6NEON DISTRICT — the pages

Night City is out. This is the clean cut, finished.

The rail is now one element, not nine. A single uninterrupted gradient runs the whole index — sodium at the top, cyan at the middle, violet at the end — and each node's colour is sampled from that gradient at the node's own measured height after layout, then handed to its offshoot and brackets. No stops, no seams, no per-segment brightness steps: the charge is one mask sliding down one gradient, so it can't kink. The sky is now the whole page. Sparse stars sit behind everything at three depths, brightest at the hero and never brighter than 40% below it, with a slow drift on the far layer and a shooting star every twenty seconds or so on a random lane. Nebula stays hero-only — it's the one place it can be strong without fighting text. Rain stayed behind with the grunge cut; it read as weather, and this world is vacuum, not street. Previews now say so: every home-page section header carries its own count and an arrow, the contact sheet strip ends in a +210 plate, and the log preview ends in a row that is itself the link.

/ LOG / REPRISEDB

Why my LSM tree was slower than a flat file

MATTHEW EMERSON2026.07.19RUST · STORAGE

I wrote reprisedb to learn how storage engines earn their reputation, and the first honest benchmark was humiliating: appending to a plain file, then scanning it linearly on read, beat my log-structured merge tree at every key count under a million.

The tree was not the problem. The tree was fine. What was killing me was that every read touched every level, and every level meant a fresh pread against a file the kernel had no reason to keep warm.

for level in &self.levels { if let Some(v) = level.get(key)? { return Ok(Some(v)); // no filter, no fence } }

Two fixes, in the order that mattered. A bloom filter per SSTable, so a level can say definitely not here for the price of a few hash rounds — that is what bloombox exists for. Then fence pointers, so a level that might have the key knows which block to read instead of walking the index.

A flat file beats a bad index because a bad index is a flat file with extra steps.

Read amplification went from six file touches to one and a bit. The flat file lost, finally, at about forty thousand keys — which is roughly where it should have lost from the start.

Energy travels, objects hold still. Light moves along things — down the rail, across a plate edge, through a sign. Boxes do not slide, scale or bounce. One light event per transition. Everything is 160-380ms except ambient loops, which are 7s and slower.

The window, not the page

Stars are pinned to the viewport — the sky is infinitely far away, so it does not move when you walk. The nebula is in the content and lags scroll; a shooting star crosses every twenty seconds or so.

into focus.

Headings arrive blurred with open tracking and resolve as they enter — a lens finding focus, not a fade-up. Body copy never does this.

One gradient, one mask. Each dot samples the rail's colour at its own measured height, so the dot, its offshoot and its brackets can never drift from the rail.
