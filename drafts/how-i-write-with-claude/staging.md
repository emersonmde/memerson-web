# Staging: How I write with Claude

META / LATER: this post is about the writing process itself — staging file → outline →
scoped section prompts → review passes → VOICE.md as a persistent style contract. It can
only be written honestly after a few posts have been through the pipeline.

The drafts directory itself is the dataset: it's tracked in git precisely so the revision
history of each post (staging → outline → draft iterations → review notes) is public
evidence of the process.

## Seeds

- Writing is *more* iterative than code because tone matters more than correctness and
  there's no compiler for voice — VOICE.md is the substitute: a style contract every
  section prompt starts from, updated when a draft teaches something new.
- Scoped section prompts keep drift down the same way scoped coding tasks do.
- The review trick that matters: critique a section against staging.md for what was
  *left out* — omissions are invisible when you only polish what's on the page.
- Collect real before/after examples from actual drafting sessions as they happen.
